# Paramètres et arguments

## Objectifs

- Définir une fonction qui reçoit un ou plusieurs paramètres.
- Distinguer un **paramètre** d'un **argument**.
- Comprendre l'association des arguments aux paramètres **par position**.
- Passer des valeurs, des variables, des expressions et des listes en argument.
- Reconnaître les erreurs liées au nombre d'arguments.

## 1. Principe

Une fonction sans paramètre fait toujours **exactement la même chose**. C'est parfait pour `afficher_entete()`, mais pas pour une fonction qui doit afficher une ligne de facture : le produit, la quantité et le prix changent d'une ligne à l'autre.

Les **paramètres** permettent de transmettre des données à une fonction pour qu'elle adapte son travail.

```python
def nom_de_la_fonction(parametre1, parametre2):
    # parametre1 et parametre2 s'utilisent comme des variables
```

## 2. Un paramètre

La facture du café utilise deux sortes de lignes de séparation : des `=` pour l'en-tête et des `-` avant les totaux. Plutôt que d'écrire deux fonctions presque identiques, on en écrit une seule qui reçoit le caractère à utiliser :

```python
LARGEUR_FACTURE = 34


def afficher_separateur(caractere):
    print(caractere * LARGEUR_FACTURE)


afficher_separateur("=")
afficher_separateur("-")
```

```text
==================================
----------------------------------
```

À chaque appel, le paramètre `caractere` reçoit la valeur placée entre les parenthèses : `"="` au premier appel, `"-"` au second.

La fonction `afficher_entete()` de la fiche [7.2](7.2%20-%20Définir%20et%20appeler%20une%20fonction.md) peut maintenant s'en servir :

```python
def afficher_entete():
    afficher_separateur("=")
    print(f"{NOM_CAFE:^{LARGEUR_FACTURE}}")
    afficher_separateur("=")
```

> 💡 `NOM_CAFE` et `LARGEUR_FACTURE` ne sont pas des paramètres de `afficher_entete()`, et pourtant la fonction peut les utiliser. Comme elles sont déclarées en haut du programme, à l'extérieur de toute fonction, ces constantes sont connues partout, y compris à l'intérieur des fonctions. On verra pourquoi en [7.5 - La portée des variables](7.5%20-%20La%20portée%20des%20variables.md).

## 3. Paramètre ou argument?

Les deux mots désignent les deux côtés d'un même échange :

| | Où? | Exemple |
| --- | --- | --- |
| **Paramètre** | Dans la **définition** : c'est une variable qui attend une valeur. | `def afficher_separateur(caractere):` |
| **Argument** | Dans l'**appel** : c'est la valeur réellement transmise. | `afficher_separateur("=")` |

> 💡 Au moment de l'appel, Python fait l'équivalent d'une affectation : `caractere = "="`, puis il exécute le corps de la fonction.

## 4. Plusieurs paramètres

Une ligne de facture a besoin de trois informations. On les sépare par des virgules, dans la définition comme dans l'appel :

```python
def afficher_ligne(produit, quantite, prix_unitaire):
    print(f"{quantite:>2} x {produit:<18}{quantite * prix_unitaire:>9.2f} $")


afficher_ligne("Café filtre", 1, 2.25)
afficher_ligne("Latté", 2, 4.50)
afficher_ligne("Biscuit", 3, 1.95)
```

```text
 1 x Café filtre            2.25 $
 2 x Latté                  9.00 $
 3 x Biscuit                5.85 $
```

### L'association se fait par position

Le **premier** argument va dans le **premier** paramètre, le deuxième dans le deuxième, et ainsi de suite. Les noms n'y sont pour rien : seul l'**ordre** compte.

```text
afficher_ligne("Latté",     2,        4.50)
                    │       │          │
                    ▼       ▼          ▼
def afficher_ligne(produit, quantite, prix_unitaire):
```

Inverser deux arguments ne provoque pas toujours d'erreur… mais donne un résultat faux :

```python
# ❌ Mauvais : quantité et prix sont inversés
afficher_ligne("Latté", 4.50, 2)
```

```text
4.5 x Latté                  9.00 $
```

### Le nombre d'arguments doit correspondre

Il faut fournir **exactement** un argument par paramètre, sinon Python lève une erreur `TypeError` :

```python
afficher_ligne("Latté", 2)
```

```text
TypeError: afficher_ligne() missing 1 required positional argument: 'prix_unitaire'
```

```python
afficher_ligne("Latté", 2, 4.50, 1)
```

```text
TypeError: afficher_ligne() takes 3 positional arguments but 4 were given
```

Le message est précis : il nomme la fonction et indique le paramètre manquant ou le nombre d'arguments attendus.

## 5. Ce qu'on peut passer en argument

Un argument peut être n'importe quelle **expression** : une valeur littérale, une variable, un calcul, un élément de tuple ou de liste, ou même le résultat d'une autre fonction.

```python
PRODUITS = ("Café filtre", "Latté", "Chocolat chaud", "Muffin", "Biscuit")
PRIX = (2.25, 4.50, 3.75, 3.25, 1.95)

# Des valeurs littérales
afficher_ligne("Muffin", 2, 3.25)

# Des variables
nom = "Muffin"
nb = 2
afficher_ligne(nom, nb, 3.25)

# Des éléments de tuples
choix = 4
afficher_ligne(PRODUITS[choix - 1], nb, PRIX[choix - 1])

# Un calcul
afficher_ligne("Muffin", nb + 1, 3.25)
```

### Le nom de la variable n'a pas d'importance

Lorsqu'on passe une variable en argument, c'est sa **valeur** qui est transmise. Son nom n'a pas besoin d'être le même que celui du paramètre :

```python
nb = 2
afficher_ligne("Muffin", nb, 3.25)   # dans la fonction, quantite vaut 2
```

La variable `nb` (dans le programme) et le paramètre `quantite` (dans la fonction) sont deux variables différentes qui contiennent, au moment de l'appel, la même valeur.

> 📌 C'est justement ce qui rend une fonction réutilisable : elle ne dépend pas des noms de variables choisis par le code qui l'appelle.

## 6. Passer une liste en argument

Une liste (ou un tuple) se passe en argument comme n'importe quelle autre valeur. La caisse mémorise la commande dans une liste `quantites`, qui contient une quantité par produit, dans le même ordre que `PRODUITS` (comme les listes associées par leur index en [6.2 - Les listes](../Cours%2006/6.2%20-%20Les%20listes.md)) :

```python
PRODUITS = ("Café filtre", "Latté", "Chocolat chaud", "Muffin", "Biscuit")
PRIX = (2.25, 4.50, 3.75, 3.25, 1.95)


def afficher_ligne(produit, quantite, prix_unitaire):
    print(f"{quantite:>2} x {produit:<18}{quantite * prix_unitaire:>9.2f} $")


def afficher_facture(quantites):
    for i in range(len(PRODUITS)):
        if quantites[i] > 0:
            afficher_ligne(PRODUITS[i], quantites[i], PRIX[i])


commande = [1, 2, 0, 0, 3]   # 1 café filtre, 2 lattés, 3 biscuits
afficher_facture(commande)
```

```text
 1 x Café filtre            2.25 $
 2 x Latté                  9.00 $
 3 x Biscuit                5.85 $
```

> ⚠️ Une fonction qui modifie le contenu d'une liste reçue en paramètre modifie aussi la liste d'origine : on verra pourquoi en [7.5 - La portée des variables](7.5%20-%20La%20portée%20des%20variables.md#5-modifier-un-paramètre--variable-simple-ou-liste).

## 7. Bonnes pratiques

### Donner des noms significatifs aux paramètres

Le nom d'un paramètre documente ce que la fonction attend.

```python
# ❌ Mauvais : que représentent a, b et c?
def afficher_ligne(a, b, c):
    ...
```

```python
# ✅ Bon
def afficher_ligne(produit, quantite, prix_unitaire):
    ...
```

### Recevoir les données en paramètres plutôt que les demander

Une fonction qui fait elle-même ses `input()` ne peut servir que dans une seule situation.

```python
# ❌ Mauvais : la fonction ne peut afficher que ce que l'utilisateur tape
def afficher_ligne():
    produit = input("Produit : ")
    quantite = int(input("Quantité : "))
    prix_unitaire = float(input("Prix : "))
    print(f"{quantite:>2} x {produit:<18}{quantite * prix_unitaire:>9.2f} $")
```

```python
# ✅ Bon : la fonction affiche n'importe quelle ligne, peu importe d'où viennent les données
def afficher_ligne(produit, quantite, prix_unitaire):
    print(f"{quantite:>2} x {produit:<18}{quantite * prix_unitaire:>9.2f} $")
```

La deuxième version peut afficher une ligne saisie au clavier, lue dans une liste ou calculée : elle est **réutilisable**.

## En résumé

- Un **paramètre** est une variable déclarée dans la définition; un **argument** est la valeur transmise lors de l'appel.
- Les arguments sont associés aux paramètres **par position** : l'ordre compte, pas les noms.
- Il faut fournir exactement un argument par paramètre, sinon : `TypeError`.
- Un argument peut être une valeur, une variable (peu importe son nom), un calcul ou une liste.
- Une fonction réutilisable reçoit ses données en paramètres plutôt que de les demander elle-même.
