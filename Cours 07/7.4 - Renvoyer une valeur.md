# Renvoyer une valeur : `return`

## Objectifs

- Renvoyer un résultat avec l'instruction `return`.
- Distinguer une fonction qui **renvoie** une valeur d'une fonction qui **affiche**.
- Utiliser la valeur renvoyée dans une variable, une expression ou un autre appel.
- Comprendre la valeur `None`.
- Utiliser `return` pour terminer une fonction plus tôt.
- Renvoyer plusieurs valeurs à l'aide d'un tuple.

## 1. Principe

Jusqu'ici, nos fonctions **affichent** des choses. Mais la plupart des fonctions de Python, comme `len()`, `round()` ou `input()`, font autre chose : elles **renvoient** un résultat au code qui les a appelées, pour que celui-ci puisse s'en servir.

L'instruction `return` permet à nos fonctions de faire la même chose.

```python
def nom_de_la_fonction(parametres):
    # calculs...
    return resultat
```

Lorsque Python exécute `return`, la fonction **se termine** et l'appel est **remplacé par la valeur renvoyée**.

## 2. Premier exemple

La caisse doit calculer le sous-total d'une commande. La fonction parcourt la liste des quantités et renvoie la somme des montants :

```python
PRIX = (2.25, 4.50, 3.75, 3.25, 1.95)


def calculer_sous_total(quantites):
    sous_total = 0.0
    for i in range(len(quantites)):
        sous_total += quantites[i] * PRIX[i]
    return sous_total


commande = [1, 2, 0, 0, 3]
montant = calculer_sous_total(commande)
print(f"Sous-total : {montant:.2f} $")
```

```text
Sous-total : 17.10 $
```

## 3. Afficher ou renvoyer?

C'est **la** distinction importante de ce cours.

| | Une fonction qui **affiche** (`print`) | Une fonction qui **renvoie** (`return`) |
| --- | --- | --- |
| Le résultat va… | à l'écran, pour l'utilisateur | au code qui a fait l'appel |
| On peut réutiliser le résultat dans un calcul | ❌ Non | ✅ Oui |
| Exemples | `afficher_menu()`, `afficher_ligne()` | `calculer_sous_total()`, `len()`, `input()` |

```python
# ❌ Mauvais : la fonction affiche le sous-total, mais on ne peut rien en faire ensuite
def calculer_sous_total(quantites):
    sous_total = 0.0
    for i in range(len(quantites)):
        sous_total += quantites[i] * PRIX[i]
    print(sous_total)
```

> 📌 **Règle pratique** : une fonction dont le nom commence par `calculer_`, `lire_` ou `est_` **renvoie** une valeur et n'affiche rien. Une fonction dont le nom commence par `afficher_` **affiche** et ne renvoie rien. On garde ainsi les calculs séparés de l'affichage.

On appelle parfois **procédure** une fonction qui ne renvoie rien et qui sert seulement à produire un effet (afficher, modifier une liste, etc.).

## 4. Utiliser la valeur renvoyée

Puisqu'un appel est remplacé par sa valeur, on peut l'utiliser **partout où une valeur est permise** :

```python
TAUX_TPS = 0.05
commande = [1, 2, 0, 0, 3]

# Dans une variable
sous_total = calculer_sous_total(commande)

# Dans une expression
tps = round(calculer_sous_total(commande) * TAUX_TPS, 2)

# Dans une condition
if calculer_sous_total(commande) > 0:
    print("Commande non vide.")

# Comme argument d'une autre fonction
print(f"Sous-total : {calculer_sous_total(commande):.2f} $")
```

```python
print(resultat)
```

## 6. Renvoyer une saisie validée

C'est ici que les fonctions deviennent vraiment utiles. La recette de validation d'un intervalle vue en [5.3 - La validation de données](../Cours%2005/5.3%20-%20La%20validation%20de%20données.md) devient une fonction qui **renvoie** la valeur, une fois qu'elle est valide :

```python
def lire_entier(message, minimum, maximum):
    valide = False
    while not valide:
        try:
            valeur = int(input(message))
            if minimum <= valeur <= maximum:
                valide = True
            else:
                print(f"Erreur : entrez un nombre entre {minimum} et {maximum}.")
        except ValueError:
            print("Erreur : ce n'est pas un nombre entier.")
    return valeur
```

La recette n'a presque pas changé. Les seules différences : le message et les bornes sont maintenant des **paramètres**, et la valeur validée est **renvoyée** à la fin.

Chaque saisie de la caisse tient maintenant en une ligne :

```python
QUANTITE_MAX = 20
PRODUITS = ("Café filtre", "Latté", "Chocolat chaud", "Muffin", "Biscuit")

choix = lire_entier("Votre choix : ", 0, len(PRODUITS))
quantite = lire_entier("Quantité : ", 1, QUANTITE_MAX)
```

```text
Votre choix : deux
Erreur : ce n'est pas un nombre entier.
Votre choix : 9
Erreur : entrez un nombre entre 0 et 5.
Votre choix : 2
Quantité : 3
```

## 7. `return` termine la fonction

Dès que Python exécute un `return`, il **quitte immédiatement** la fonction, même s'il reste des instructions ou si on est au milieu d'une boucle. Une fonction peut donc contenir plusieurs `return`, dans des branches différentes.

La caisse doit demander si le client a sa carte étudiante. La fonction renvoie `True` ou `False` selon la réponse :

```python
def lire_oui_non(message):
    reponses_valides = ("o", "n")
    reponse = input(message).strip().lower()
    while reponse not in reponses_valides:
        print("Erreur : répondez par o ou n.")
        reponse = input(message).strip().lower()

    if reponse == "o":
        return True
    else:
        return False


if lire_oui_non("Carte étudiante? (o/n) : "):
    print("Rabais de 10 % appliqué.")
```

Comme `reponse == "o"` est déjà une expression booléenne qui vaut `True` ou `False`, on peut la renvoyer directement :

```python
    return reponse == "o"
```

> 💡 Les deux versions sont équivalentes. La seconde est plus courte, mais la première est parfaitement acceptable si elle te semble plus claire.

### Code mort

Une instruction placée **après** un `return` dans le même bloc ne sera jamais exécutée :

```python

def calculer_rabais(montant, taux):
    return round(montant * taux, 2)
    print("Rabais calculé!")
```

## 8. Renvoyer plusieurs valeurs

Une fonction ne renvoie qu'**une seule** valeur… mais cette valeur peut être un **tuple** qui en regroupe plusieurs. Il suffit de les séparer par des virgules après `return`.

Au Québec, on calcule deux taxes sur une vente :

```python
TAUX_TPS = 0.05
TAUX_TVQ = 0.09975


def calculer_taxes(montant):
    tps = round(montant * TAUX_TPS, 2)
    tvq = round(montant * TAUX_TVQ, 2)
    return tps, tvq
```

On peut récupérer le tuple et accéder à ses éléments par leur index, comme vu en [5.3](../Cours%2005/5.3%20-%20La%20validation%20de%20données.md) :

```python
taxes = calculer_taxes(15.39)
print(taxes)                     # (0.77, 1.54)
print(f"TPS : {taxes[0]:.2f} $")
print(f"TVQ : {taxes[1]:.2f} $")
```

```python
tps, tvq = calculer_taxes(15.39)
print(f"TPS : {tps:.2f} $")      # TPS : 0.77 $
print(f"TVQ : {tvq:.2f} $")      # TVQ : 1.54 $
```

## En résumé

- `return valeur` termine la fonction et renvoie `valeur` au code qui l'a appelée.
- L'appel est **remplacé par la valeur renvoyée** : on peut l'utiliser dans une variable, une expression, une condition ou un autre appel.
- **Afficher n'est pas renvoyer** : une fonction de calcul renvoie son résultat, elle ne l'affiche pas.
- Sans `return`, une fonction renvoie `None`.
- Une fonction peut contenir plusieurs `return`; le premier exécuté termine la fonction.
- Pour renvoyer plusieurs valeurs, on renvoie un tuple : `return tps, tvq`, puis `tps, tvq = calculer_taxes(montant)`.
