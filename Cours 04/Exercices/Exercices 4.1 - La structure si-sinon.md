# Exercices — La structure si-sinon (fiche 4.1)

## 🟢 Exercice 1 : Facile

**But** : Distinguer deux cas avec `if`/`else`.

**Énoncé** : Écris un programme qui demande un nombre entier à l'utilisateur.

- Si le nombre est strictement négatif, affiche : *"Nombre négatif"*.
- Sinon, affiche : *"Nombre positif ou nul"*.

## 🟢 Exercice 2 : Facile-Moyen

**But** : Vérifier une condition d'âge simple.

**Énoncé** : Écris un programme qui demande l'âge de l'utilisateur.

- Si l'âge est de 18 ans ou plus, affiche : *"Majeur"*.
- Sinon, affiche : *"Mineur"*.



## 🟡 Exercice 3 : Moyen

**But** : Valider la longueur d'un mot de passe.

**Énoncé** : Écris un programme qui demande un mot de passe à l'utilisateur.

- Si le mot de passe contient au moins 8 caractères, affiche : *"Mot de passe accepté"*.
- Sinon, affiche : *"Mot de passe trop court"*.

| Entrée | Sortie |
| :---: | --- |
| `abc123` | Mot de passe trop court |
| `motdepasse2026` | Mot de passe accepté |

## 🟡 Exercice 4 : Moyen

**But** : Vérifier un multiple.

**Énoncé** : Écris un programme qui demande un nombre entier à l'utilisateur.

- Si le nombre est un multiple de 3, affiche : *"Multiple de 3"*.
- Sinon, affiche : *"N'est pas un multiple de 3"*.

## 🔴 Exercice 5 : Moyen-Difficile

**But** : Combiner une condition avec `or` dans un `if`/`else`.

**Énoncé** : Écris un programme qui demande la longueur des 3 côtés d'un triangle (`a`, `b`, `c`).

- Si **au moins deux côtés** sont égaux, affiche : *"Triangle isocèle"*.
- Sinon, affiche : *"Triangle scalène"*.

| a | b | c | Sortie |
| :---: | :---: | :---: | --- |
| `5` | `5` | `8` | Triangle isocèle |
| `4` | `4` | `4` | Triangle isocèle |
| `3` | `4` | `5` | Triangle scalène |
