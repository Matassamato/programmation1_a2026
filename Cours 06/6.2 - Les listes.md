# Les listes en Python

## Objectifs

- Comprendre ce qu'est une liste et à quoi elle sert.
- Créer une liste, accéder à ses éléments et les modifier.
- Utiliser les fonctions et méthodes les plus courantes sur les listes.
- Parcourir une liste avec une boucle `for`.
- Construire une liste au fil d'une boucle.
- Éviter les pièges les plus fréquents (alias, modification pendant un parcours, index hors limites).

## 1. Principe

Une **liste** (`list`) est une variable qui contient **plusieurs valeurs**, rangées dans un ordre précis. Au lieu de créer `note1`, `note2`, `note3`, … on regroupe toutes les notes dans une seule variable.

```python
notes = [78, 92, 65, 88]
print(notes)          # [78, 92, 65, 88]
print(type(notes))    # <class 'list'>
```

Une liste est :

- **ordonnée** : chaque élément a une position (son **index**), qui commence à `0`;
- **modifiable** : on peut ajouter, retirer ou remplacer des éléments après sa création;
- **flexible** : sa taille change selon les besoins, et elle peut contenir n'importe quel type de valeur.

> 💡 Le **tuple** vu en [5.3 - La validation de données](../Cours%2005/5.3%20-%20La%20validation%20de%20données.md) ressemble beaucoup à une liste, mais il est **non modifiable** : on l'écrit avec des parenthèses `( )`, alors que la liste utilise des crochets `[ ]`.

## 2. Créer une liste

| Façon | Exemple | Résultat |
| --- | --- | --- |
| Liste vide | `fruits = []` | `[]` |
| Liste avec des valeurs | `fruits = ["pomme", "poire", "kiwi"]` | `['pomme', 'poire', 'kiwi']` |
| À partir d'un `range()` | `list(range(1, 6))` | `[1, 2, 3, 4, 5]` |
| À partir d'une chaîne | `list("abc")` | `['a', 'b', 'c']` |
| En découpant une chaîne | `"rouge,vert,bleu".split(",")` | `['rouge', 'vert', 'bleu']` |
| En découpant aux espaces | `"le chat dort".split()` | `['le', 'chat', 'dort']` |

```python
nombres = [4, 8, 15, 16, 23, 42]
prenoms = ["Léa", "Samuel", "Noah"]
melange = [12, "douze", 12.0, True]    # permis, mais rarement une bonne idée
```

> 💡 Dans la pratique, une liste contient presque toujours des valeurs **du même type** (que des notes, que des prénoms, etc.).

La méthode `split()` est très utile pour obtenir plusieurs valeurs en une seule saisie :

```python
saisie = input("Entrez vos couleurs préférées, séparées par des virgules : ")
couleurs = saisie.split(",")
```

## 3. Accéder aux éléments

### Par index

On accède à un élément avec des crochets, exactement comme pour un caractère dans une chaîne.

```python
fruits = ["pomme", "poire", "kiwi", "mangue"]
#   index :    0        1       2        3
#   négatif : -4       -3      -2       -1

print(fruits[0])     # pomme
print(fruits[2])     # kiwi
print(fruits[-1])    # mangue (le dernier)
```

### Par tranche (*slicing*)

La notation par tranche fonctionne comme pour les chaînes (voir [Manipulations de chaînes](../Outils/Manipulations%20de%20chaînes.md)) et produit une **nouvelle liste**.

```python
print(fruits[1:3])    # ['poire', 'kiwi']
print(fruits[:2])     # ['pomme', 'poire']
print(fruits[::-1])   # ['mangue', 'kiwi', 'poire', 'pomme']
```

### L'erreur `IndexError`

Accéder à un index qui n'existe pas provoque une erreur.

```python
fruits = ["pomme", "poire", "kiwi"]
print(fruits[3])    # IndexError: list index out of range
```

Le dernier index valide est toujours `len(liste) - 1`.

## 4. Modifier une liste

Contrairement à une chaîne, une liste peut être modifiée **directement**.

```python
mot = "chat"
mot[0] = "C"        # ❌ TypeError : une chaîne n'est pas modifiable

animaux = ["chat", "chien"]
animaux[0] = "Chat" # ✅ une liste est modifiable
print(animaux)      # ['Chat', 'chien']
```

### Quelques méthodes pour manipuler les listes

Le tableau suivant regroupe les opérations qui **modifient** une liste. La première ligne n'est pas une méthode, mais l'affectation par index vue ci-dessus. Les exemples **s'enchaînent** : chaque ligne part du résultat de la ligne précédente, en commençant avec `l = [10, 20, 30]`.

| Opération | Description | Exemple | `l` après l'opération |
| --- | --- | --- | --- |
| `l[i] = valeur` | Remplace l'élément à l'index `i`. | `l[1] = 99` | `[10, 99, 30]` |
| `l.append(valeur)` | Ajoute `valeur` **à la fin**. | `l.append(40)` | `[10, 99, 30, 40]` |
| `l.insert(i, valeur)` | Insère `valeur` **à l'index** `i`; les suivants sont décalés. | `l.insert(0, 5)` | `[5, 10, 99, 30, 40]` |
| `l.remove(valeur)` | Retire la **première occurrence** de `valeur`. `ValueError` si absente. | `l.remove(99)` | `[5, 10, 30, 40]` |
| `l.pop()` | Retire **et retourne** le dernier élément. | `x = l.pop()` | `[5, 10, 30]`, `x` vaut `40` |
| `l.pop(i)` | Retire **et retourne** l'élément à l'index `i`. | `x = l.pop(0)` | `[10, 30]`, `x` vaut `5` |
| `l.clear()` | Vide la liste. | `l.clear()` | `[]` |

```python
epicerie = []
epicerie.append("lait")
epicerie.append("pain")
epicerie.append("œufs")
print(epicerie)              # ['lait', 'pain', 'œufs']

epicerie.remove("pain")
print(epicerie)              # ['lait', 'œufs']
```

> ⚠️ Les méthodes qui modifient la liste (`append`, `insert`, `remove`, `sort`, …) **ne retournent rien** (`None`). On ne les utilise donc pas dans une affectation :
>
> ```python
> epicerie = epicerie.append("beurre")   # ❌ epicerie vaut maintenant None!
> epicerie.append("beurre")              # ✅
> ```

## 5. Opérations et fonctions utiles

Contrairement au tableau précédent, les opérations suivantes servent surtout à **obtenir de l'information** sur une liste (sa taille, sa somme, la présence d'une valeur, etc.) ou à en produire une **nouvelle**, sans modifier l'originale. Seules `sort()` et `reverse()` modifient la liste elle-même. Tous les exemples utilisent `l = [3, 1, 4, 1, 5]`.

| Nom | Description | Exemple (`l = [3, 1, 4, 1, 5]`) | Résultat |
| --- | --- | --- | --- |
| `len(l)` | Nombre d'éléments. | `len(l)` | `5` |
| `valeur in l` | Vérifie si `valeur` fait partie de la liste. | `4 in l` | `True` |
| `valeur not in l` | Vérifie si `valeur` est absente. | `9 not in l` | `True` |
| `sum(l)` | Somme des éléments (nombres seulement). | `sum(l)` | `14` |
| `min(l)` / `max(l)` | Plus petit / plus grand élément. | `max(l)` | `5` |
| `l.count(valeur)` | Nombre d'occurrences de `valeur`. | `l.count(1)` | `2` |
| `l.index(valeur)` | Index de la première occurrence. `ValueError` si absente. | `l.index(4)` | `2` |
| `l.sort()` | Trie **la liste elle-même** (ne retourne rien). | `l.sort()` | `l` devient `[1, 1, 3, 4, 5]` |
| `l.sort(reverse=True)` | Trie en ordre décroissant. | `l.sort(reverse=True)` | `l` devient `[5, 4, 3, 1, 1]` |
| `sorted(l)` | Retourne une **nouvelle** liste triée; `l` n'est pas modifiée. | `sorted(l)` | `[1, 1, 3, 4, 5]` |
| `l.reverse()` | Inverse l'ordre de la liste elle-même. | `l.reverse()` | `l` devient `[5, 1, 4, 1, 3]` |
| `l1 + l2` | Concatène deux listes (nouvelle liste). | `[1, 2] + [3]` | `[1, 2, 3]` |
| `l * n` | Répète la liste `n` fois (nouvelle liste). | `[0] * 3` | `[0, 0, 0]` |
| `", ".join(l)` | Assemble une liste de **chaînes** en une seule chaîne. | `", ".join(["a", "b"])` | `'a, b'` |

### `sort()` ou `sorted()`?

```python
notes = [78, 92, 65]

triees = sorted(notes)    # nouvelle liste
print(notes)              # [78, 92, 65]  ← inchangée
print(triees)             # [65, 78, 92]

notes.sort()              # modifie notes elle-même
print(notes)              # [65, 78, 92]
```

- `sorted(l)` lorsqu'on veut **conserver** la liste originale.
- `l.sort()` lorsque l'ordre original n'a plus d'importance.

### Valider avec `in` avant d'utiliser `remove()` ou `index()`

```python
fruits = ["pomme", "poire"]
choix = input("Quel fruit retirer? ").strip().lower()
if choix in fruits:
    fruits.remove(choix)
else:
    print("Ce fruit n'est pas dans la liste.")
```

## 6. Parcourir une liste avec `for`

### Parcours par *élément*

C'est la forme la plus courante et la plus lisible.

```python
prenoms = ["Léa", "Samuel", "Noah"]
for prenom in prenoms:
    print("Bonjour", prenom)
```

### Parcours par *index*

Nécessaire lorsqu'on a besoin de la **position** de l'élément ou qu'on veut **modifier** la liste.

```python
prenoms = ["Léa", "Samuel", "Noah"]
for i in range(len(prenoms)):
    print(f"{i + 1}. {prenoms[i]}")
```

```text
1. Léa
2. Samuel
3. Noah
```

> ⚠️ On écrit bien `range(len(prenoms))`, et **non** `range(1, len(prenoms) + 1)` : les index d'une liste vont de `0` à `len(prenoms) - 1`. Commencer à `1` ferait sauter le premier élément, et aller jusqu'à `len(prenoms)` provoquerait une `IndexError` au dernier tour. Pour **afficher** une numérotation qui commence à 1, on ajoute plutôt `1` au moment de l'affichage (`i + 1`).

### Modifier chaque élément

La variable d'itération n'est qu'une **copie de la valeur** : la modifier ne change pas la liste. Il faut passer par l'index.

```python
prix = [10.0, 25.0, 40.0]

# ❌ Mauvais : la liste n'est pas modifiée
for p in prix:
    p = p * 1.15

print(prix)    # [10.0, 25.0, 40.0]  ← aucun changement!

# ✅ Bon : on modifie la liste par son index
for i in range(len(prix)):
    prix[i] = round(prix[i] * 1.15, 2)

print(prix)    # [11.5, 28.75, 46.0]
```

## 7. Construire une liste dans une boucle

Le patron est toujours le même : **liste vide avant la boucle**, puis `append()` à chaque tour.

### Nombre d'éléments connu → `for`

```python
NB_NOTES = 4
notes = []
for i in range(1, NB_NOTES + 1):
    note = float(input(f"Note {i} : "))
    notes.append(note)

print("Notes :", notes)
print(f"Moyenne : {sum(notes) / len(notes):.2f}")
```

### Nombre d'éléments inconnu → `while` avec sentinelle

```python
prenoms = []
prenom = input("Prénom (Entrée pour terminer) : ").strip()
while prenom != "":
    prenoms.append(prenom)
    prenom = input("Prénom (Entrée pour terminer) : ").strip()

print(f"{len(prenoms)} prénom(s) saisi(s) :", ", ".join(prenoms))
```

### À partir d'une autre liste

```python
temperatures_c = [-5, 0, 12, 23]
temperatures_f = []
for t in temperatures_c:
    temperatures_f.append(t * 9 / 5 + 32)
print(temperatures_f)    # [23.0, 32.0, 53.6, 73.4]
```

## 8. Pièges et bonnes pratiques

### `b = a` ne copie pas la liste

L'affectation crée un **deuxième nom** (un *alias*) pour **la même liste**. Modifier l'une modifie l'autre.

```python
# ❌ Piège : les deux noms désignent la même liste
originale = [1, 2, 3]
copie = originale
copie.append(4)
print(originale)    # [1, 2, 3, 4]  ← surprise!
```

```python
# ✅ Bon : on crée une vraie copie
originale = [1, 2, 3]
copie = originale.copy()    # ou originale[:]
copie.append(4)
print(originale)    # [1, 2, 3]
```

### Ne pas ajouter ou retirer d'éléments pendant qu'on parcourt la liste

Retirer des éléments d'une liste pendant qu'on la parcourt décale les index et fait **sauter** des éléments.

```python
# ❌ Mauvais : le 2e zéro n'est pas retiré
nombres = [0, 0, 5, 7]
for n in nombres:
    if n == 0:
        nombres.remove(n)
print(nombres)    # [0, 5, 7]
```

```python
# ✅ Bon : on construit une nouvelle liste avec les éléments à garder
nombres = [0, 0, 5, 7]
non_nuls = []
for n in nombres:
    if n != 0:
        non_nuls.append(n)
print(non_nuls)    # [5, 7]
```

### Utiliser `range(len(liste))`, pas `range(len(liste) + 1)`

```python
# ❌ Mauvais : IndexError au dernier tour
for i in range(len(notes) + 1):
    print(notes[i])
```

```python
# ✅ Bon
for i in range(len(notes)):
    print(notes[i])
```

### Vérifier qu'une liste n'est pas vide avant certains calculs

`sum(l) / len(l)` provoque une `ZeroDivisionError`, et `max(l)` une `ValueError`, si la liste est vide.

```python
if len(notes) > 0:
    print("Moyenne :", sum(notes) / len(notes))
else:
    print("Aucune note saisie.")
```

### Nommer les listes au pluriel

Un nom au pluriel pour la liste et au singulier pour l'élément rend la boucle naturelle à lire.

```python
for etudiant in etudiants:
    ...
```

## 9. Usages typiques des listes

### 1. Filtrer : garder les éléments qui respectent une condition

```python
notes = [78, 45, 92, 58, 88]
reussites = []
for note in notes:
    if note >= 60:
        reussites.append(note)
print(reussites)    # [78, 92, 88]
```

### 2. Transformer : appliquer une opération à chaque élément

```python
noms = ["léa", "samuel", "noah"]
noms_majuscules = []
for nom in noms:
    noms_majuscules.append(nom.capitalize())
print(noms_majuscules)    # ['Léa', 'Samuel', 'Noah']
```

### 3. Rechercher : trouver la position d'un élément

```python
inventaire = ["vis", "clou", "boulon", "écrou"]
recherche = "boulon"
position = -1
for i in range(len(inventaire)):
    if inventaire[i] == recherche:
        position = i
        break

if position != -1:
    print(recherche, "trouvé à l'index", position)
else:
    print(recherche, "introuvable")
```

### 4. Calculer des statistiques

```python
temperatures = [-3, 2, 5, -1, 8, 4]
print("Minimum :", min(temperatures))
print("Maximum :", max(temperatures))
print(f"Moyenne : {sum(temperatures) / len(temperatures):.1f}")

jours_sous_zero = 0
for t in temperatures:
    if t < 0:
        jours_sous_zero += 1
print("Jours sous zéro :", jours_sous_zero)
```

### 5. Associer deux listes par leur index

Deux listes de même longueur peuvent représenter des informations liées : l'élément `i` de l'une correspond à l'élément `i` de l'autre.

```python
produits = ["café", "muffin", "jus"]
prix = [2.50, 3.25, 4.00]
for i in range(len(produits)):
    print(f"{produits[i]:<10}{prix[i]:>6.2f} $")
```

## En résumé

- Une liste regroupe plusieurs valeurs ordonnées dans une seule variable : `[val1, val2, ...]`.
- Les index commencent à `0`; le dernier est `len(liste) - 1` (ou `-1`).
- Une liste est **modifiable** : `liste[i] = ...`, `append()`, `insert()`, `remove()`, `pop()`.
- `for element in liste` pour lire chaque élément; `for i in range(len(liste))` pour connaître la position ou modifier la liste.
- Pour construire une liste : liste vide avant la boucle, `append()` dans la boucle.
- `b = a` ne copie pas une liste : utiliser `a.copy()`.
