# La boucle `while` en Python

## Objectifs

- Comprendre la structure d'une boucle `while`.
- Apprendre à contrôler une boucle avec une condition.
- Éviter les boucles infinies.
- Utiliser une variable de contrôle booléenne (drapeau) plutôt qu'une comparaison de chaînes.

## 1. Principe

La boucle `while` permet de répéter un bloc de code **tant qu'une condition est vraie**.
Elle est utilisée quand le nombre d'itérations n'est pas connu à l'avance.

## 2. Syntaxe

```python
while condition:
    # instructions répétées tant que `condition` est vraie
```

- `condition` doit être une expression booléenne (`True` ou `False`).
- Le bloc à l'intérieur doit être indenté.
- Si la condition est fausse dès le départ, le code à l'intérieur n'est jamais exécuté.

## 3. Exemple simple

```python
compteur = 1
while compteur <= 5:
    print(compteur)
    compteur += 1
```

Ce code affiche les nombres de 1 à 5.

## 4. Contrôler la sortie

### La variable de contrôle

- On appelle **variable de contrôle** une variable présente dans la condition d'une boucle `while`.
- Elle doit être **initialisée** avant la boucle et **mise à jour** à l'intérieur de celle-ci.
- Sans cette mise à jour, la condition reste vraie et la boucle ne s'arrête jamais.
- C'est elle qui détermine, à chaque tour, si la boucle doit continuer ou s'arrêter.

#### Exemple avec variable de contrôle

```python
reponse = ""    # valeur initiale de la variable de contrôle
while reponse != "oui":     # condition basée sur la variable de contrôle
    reponse = input("Voulez-vous continuer ? ").strip().lower() # mise à jour de la variable de contrôle
```

Ici la boucle se termine lorsque l'utilisateur tape `oui`, peu importe la casse.

#### Exemple avec une variable de contrôle booléenne

La variable de contrôle n'a pas à être une chaîne de caractères : c'est souvent un **booléen**, c'est-à-dire une variable qui ne vaut que `True` ou `False`. La condition devient alors directement lisible, sans comparaison.

```python
continuer = True        # la variable de contrôle est un booléen
while continuer:        # se lit : « tant que continuer est vrai »
    nombre = int(input("Entrez un nombre : "))
    print("Le double est", nombre * 2)

    reponse = input("Un autre ? (o/n) ").strip().lower()
    continuer = (reponse == "o")    # la comparaison produit déjà True ou False
```

À retenir : `reponse == "o"` **est** une expression booléenne. On peut donc ranger son résultat dans une variable plutôt que de le comparer à nouveau.

#### Le drapeau (`flag`)

Quand la condition d'arrêt se détecte à l'intérieur du bloc, on utilise un booléen appelé **drapeau** : il est levé (`True`) au moment où l'événement se produit. L'opérateur `not` permet alors d'écrire une condition qui se lit en français.

```python
trouve = False          # le drapeau est baissé au départ
while not trouve:       # se lit : « tant que ce n'est pas trouvé »
    essai = int(input("Devinez le nombre : "))
    if essai == 42:
        trouve = True   # on lève le drapeau : la boucle s'arrêtera
    else:
        print("Ce n'est pas ça.")

print("Bravo !")
```

Le drapeau a un avantage sur le `break` : après la boucle, il **reste disponible** et permet de savoir *pourquoi* on en est sorti.

```python
essais_restants = 3
acces_autorise = False              # drapeau

while essais_restants > 0 and not acces_autorise:
    mot_de_passe = input("Mot de passe : ").strip()
    if mot_de_passe == "python123":
        acces_autorise = True
    else:
        essais_restants -= 1
        print("Refusé. Essais restants :", essais_restants)

if acces_autorise:                  # le drapeau sert encore ici
    print("Bienvenue !")
else:
    print("Compte bloqué.")
```

Remarquez la condition composée : la boucle continue tant qu'il reste des essais **et** que l'accès n'est pas accordé. Deux façons de sortir, une seule boucle.

### Interrompre complètement la boucle avec `break`

- L'instruction `break` arrête **immédiatement** la boucle, sans même revérifier la condition.
- Utile lorsque la condition d'arrêt est plus simple à détecter à l'intérieur du bloc qu'à écrire dans l'en-tête du `while`.
- On l'utilise souvent avec `while True`, qui crée une boucle qui ne s'arrête que par un `break`.

```python
while True:
    reponse = input("Voulez-vous continuer ? (oui/non) ").strip().lower()
    if reponse == "non":
        break   # sort immédiatement de la boucle
    print("On continue...")
```

### Passer à l'itération suivante avec `continue`

- L'instruction `continue` interrompt seulement **l'itération courante** : le reste du bloc est ignoré et Python retourne évaluer la condition du `while`.
- Contrairement à `break`, la boucle n'est pas arrêtée, elle passe simplement au tour suivant.
- Attention : la variable de contrôle doit tout de même être mise à jour **avant** le `continue`, sinon la boucle peut devenir infinie.

```python
compteur = 0
while compteur < 10:
    compteur += 1
    if compteur % 2 != 0:
        continue   # ignore le reste du bloc pour les nombres impairs
    print(compteur)
```

Ce code affiche uniquement les nombres pairs de 2 à 10.

## 5. Bonnes pratiques

### Initialiser la variable de contrôle avant la boucle

Sans initialisation, la variable de contrôle n'existe pas encore au moment où Python évalue la condition.

```python
# ❌ Mauvais : compteur n'est jamais défini avant la boucle
while compteur <= 5:
    print(compteur)
    compteur += 1
```

```python
# ✅ Bon : compteur est initialisé avant la boucle
compteur = 1
while compteur <= 5:
    print(compteur)
    compteur += 1
```

### Mettre à jour la variable de contrôle dans la boucle

Si la variable de contrôle n'est jamais modifiée à l'intérieur de la boucle, la condition reste vraie indéfiniment et la boucle ne s'arrête jamais.

```python
# ❌ Mauvais : boucle infinie, compteur n'est jamais modifié
compteur = 1
while compteur <= 5:
    print(compteur)
```

```python
# ✅ Bon : compteur est mis à jour à chaque itération
compteur = 1
while compteur <= 5:
    print(compteur)
    compteur += 1
```

### Ne pas comparer un booléen à `True` ou à `False`

Une variable booléenne est **déjà** la condition : la comparer à `True` n'ajoute rien et alourdit la lecture.

```python
# ❌ Mauvais : comparaison redondante
continuer = True
while continuer == True:
    ...
```

```python
# ✅ Bon : le booléen est la condition
continuer = True
while continuer:
    ...
```

Pour le cas inversé, on utilise `not` plutôt qu'une comparaison à `False` :

```python
# ❌ Mauvais
while trouve == False:
    ...
```

```python
# ✅ Bon
while not trouve:
    ...
```

### Utiliser un message clair pour l'utilisateur

Dans une boucle de saisie, un message vague peut laisser l'utilisateur sans indication sur ce qui est attendu ou sur comment sortir de la boucle.

```python
# ❌ Mauvais : l'utilisateur ne sait pas quoi taper pour arrêter
reponse = ""
while reponse != "oui":
    reponse = input("Continuer ? ").strip().lower()
```

```python
# ✅ Bon : le message précise la valeur attendue pour sortir
reponse = ""
while reponse != "oui":
    reponse = input("Voulez-vous continuer ? (tapez 'oui' pour continuer) ").strip().lower()
```

## 6. Usages typiques de la boucle `while`

### 1. Valider une saisie utilisateur

Répéter la demande tant que la valeur entrée n'est pas acceptable.

```python
age = int(input("Entrez votre âge : "))
while age < 0 or age > 120:
    print("Âge invalide.")
    age = int(input("Entrez votre âge : "))
```

### 2. Créer un menu répété

Réafficher un menu tant que l'utilisateur n'a pas choisi de quitter.

```python
choix = ""
while choix != "q":
    choix = input("Tapez 'q' pour quitter : ").strip().lower()
```

### 3. Répéter un nombre d'itérations connu (compteur)

Utiliser une variable de contrôle qui joue le rôle d'un compteur, comme alternative à `for`.

```python
compteur = 0
while compteur < 10:
    print(compteur)
    compteur += 1
```

### 4. Accumuler des valeurs jusqu'à une sentinelle

Additionner ou traiter des valeurs saisies une à une, jusqu'à ce qu'une valeur spéciale (sentinelle) signale l'arrêt.

```python
total = 0
nombre = int(input("Entrez un nombre (0 pour arrêter) : "))
while nombre != 0:
    total += nombre
    nombre = int(input("Entrez un nombre (0 pour arrêter) : "))
print("Somme :", total)
```

### 5. Répéter jusqu'à l'atteinte d'un objectif (boucle de recherche)

Continuer tant qu'une condition liée à un résultat recherché n'est pas atteinte, par exemple deviner un nombre.

```python
nombre_secret = 7
essai = int(input("Devinez le nombre : "))
while essai != nombre_secret:
    essai = int(input("Essayez encore : "))
print("Bravo, vous avez trouvé !")
```

### 6. Continuer tant qu'un drapeau n'est pas levé

Utiliser un booléen lorsque l'arrêt dépend d'un événement détecté dans le bloc, ou lorsqu'on doit savoir après la boucle comment elle s'est terminée.

```python
partie_terminee = False
vies = 3

while not partie_terminee:
    reponse = input("Combien font 6 x 7 ? ").strip()

    if reponse == "42":
        print("Exact !")
        partie_terminee = True
    else:
        vies -= 1
        print("Raté. Vies restantes :", vies)
        if vies == 0:
            partie_terminee = True
```

## En résumé

- `while` : boucle conditionnelle.
- Utile quand on ne connaît pas le nombre d'itérations à l'avance.
- Ne pas oublier de mettre à jour l'état de la condition.
- La variable de contrôle est souvent un **booléen** (`continuer`, `trouve`, `partie_terminee`) : on écrit `while continuer:` ou `while not trouve:`, jamais `while continuer == True:`.
